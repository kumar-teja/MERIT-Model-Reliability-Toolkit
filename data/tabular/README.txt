MERIT generated tabular teaching data (not real animal measurements).
All four files have 1,000 balanced dog/wolf labels and the same noisy
genuine_signal construction. background_shortcut is a controlled
categorical cue: wolf -> snow and dog -> green_field at the stated
agreement rate. Values are generated with seed 20261109.

Suggested comparison in MERIT: upload each file, select animal as
target, select background_shortcut as the feature to investigate,
and shuffle it on the held-out split. Compare baseline scores across
the intended-only, independent, strong, and reversed scenarios.
These data illustrate an experimental design; they are not evidence
about real dogs, wolves, or computer-vision systems.
