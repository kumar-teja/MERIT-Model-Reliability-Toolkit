All synthetic_*.zip archives contain generated illustrations, not photos.
Each archive has 160 images: 80 of each stylized class; each class has 56
images on its common background and 24 on the alternate background. The
intended silhouette cue is deliberately small while background color and
texture are prominent. These demonstrate the app workflow only; they are
not real research images or evidence about actual animal recognition.
See the project README for real benchmark sources and limitations.
